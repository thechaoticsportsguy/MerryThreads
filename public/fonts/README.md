# Gambetta

Original, unmodified WOFF2 files downloaded from Fontshare on September 5, 2026:
https://www.fontshare.com/fonts/gambetta

Official download: https://api.fontshare.com/v2/fonts/download/gambetta

Only the styles used by this site are included: Regular (400), Medium (500),
and Italic (400), approximately 69 KiB total. The accompanying Fontshare
license is retained in Gambetta-LICENSE.txt. These are site assets, not a
standalone font distribution or an invitation to reuse the font elsewhere.

`app/layout.js` loads these files with `next/font/local` and `display: swap`.
The shared `--font-display` token points to `--font-gambetta` in globals.css.
Hanken Grotesk remains the sans-serif for body copy, prices, and UI; Next.js
serves its generated font assets locally as before.
